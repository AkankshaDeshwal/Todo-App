📝 Todo App

A clean and responsive Todo App built using JavaScript to manage daily tasks efficiently. This project demonstrates core frontend concepts like DOM manipulation, event handling, and CRUD operations.

🚀 Features
➕ Add new tasks
❌ Delete tasks
✅ Strick off completed tasks
🎯 Real-time UI updates with JavaScript

🛠️ Tech Stack
HTML5
CSS3
JavaScript (Vanilla JS)

🧠 What I Learned
Manipulating the DOM dynamically using JavaScript
Handling user input and events efficiently
Structuring small projects for scalability
Writing clean and readable code

⚠️ Limitations
Data is stored in memory and resets on browser refresh
No backend or persistent storage implemented yet

🔮 Future Improvements
- Add localStorage support for data persistence
- Integrate a backend (Node.js / Firebase)
- Improve mobile responsiveness
- Enhance UI/UX with animations
